# UI mockups (static reference)

Static HTML copies (with PNG screenshots) of the mockup canvas (https://claude.ai/artifact/94a4dJBRDVaksUSy8BLM5a). Open in a browser.

- Values are placeholders (`[lookup value]`, `Vendor A`, `[catalog no]`), not BioA data.
- They show layout and look, not behavior. Behaviors (navigation, scrolling, sticky bar, dropdowns, bulk actions) are in `../UI_SPEC.md`.
- Where a mockup and `../UI_SPEC.md` differ, `UI_SPEC.md` wins.

| File | Screen |
|---|---|
| `1_start_run.html` | Start a run: run name, upload, file list, recent runs |
| `2_processing.html` | Processing: step list |
| `3_review_and_resolve.html` | Review: summary, grid with Action needed and Found in, resolution panel, bottom action bar |
| `3b_verify_dialog.html` | Verify dialog when issues remain |
| `4_admin_lookup_lists.html` | Admin: lookup lists |
